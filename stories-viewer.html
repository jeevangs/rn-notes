Stories Viewer — Composite Build

Progressive, block-by-block: a horizontal tile row opens a fullscreen modal that plays N image segments per story, auto-advancing on a timer with progress bars and tap-to-navigate.

Architecture & build order

The viewer is a small state machine driven by two indices: which story, and which segment within it. A single setTimeout advances the segment after its duration; the progress bars are a pure render of segmentIndex. The timer is the one piece that must be cleaned up on every segment change — that is the stale-closure trap.

stories: Story[]            ← data (row of tiles)
   │ tap a tile
   ▼
viewer state machine   { storyIndex, segmentIndex, paused }
   │                          ▲
   │ setTimeout(duration)     │ progress bars derived from segmentIndex
   ▼                          │
goNext ──► segmentIndex + 1 ──┤  (last segment? → next story → close)
goPrev ──► segmentIndex - 1 ──┘
   ▲
tap-left / tap-right zones · hold-to-pause · AppState pause

Build order — keep something runnable at every step: tiles → open modal → show one image → auto-advance → progress + taps → harden. Each step below leaves a working app.

ATypes / data model

A Story is an author plus an ordered list of segments. Each segment carries its own image uri and a duration in ms — different segments can linger for different lengths. duration is optional in the payload; the viewer falls back to DEFAULT_DURATION.

import { z } from 'zod';

const SegmentSchema = z.object({
  uri: z.string(),                       // image url for this frame
  duration: z.number().optional(),       // ms on screen → drives the timer
});

const StorySchema = z.object({
  id: z.string(),
  authorName: z.string(),
  avatarUri: z.string(),
  segments: z.array(SegmentSchema),      // N frames, played in order
});
const StoriesSchema = z.array(StorySchema);

type Segment = z.infer<typeof SegmentSchema>;
type Story = z.infer<typeof StorySchema>;

BTile row — memoized, horizontal

A horizontal FlatList of memoized StoryTile (avatar ring + name). onPress opens the viewer at that story. Memo + a stable onPress keep tiles from re-rendering as the viewer state churns.

const StoryTile = memo(function StoryTile({
  story, onPress,
}: { story: Story; onPress: (id: string) => void }) {
  return (
    <Pressable style={styles.tile} onPress={() => onPress(story.id)}>
      <View style={styles.ring}>
        <Image source={{ uri: story.avatarUri }} style={styles.avatar} />
      </View>
      <Text numberOfLines={1} style={styles.tileName}>{story.authorName}</Text>
    </Pressable>
  );
});

function StoryRow({ stories, onOpen }: { stories: Story[]; onOpen: (id: string) => void }) {
  return (
    <FlatList
      data={stories}
      horizontal
      showsHorizontalScrollIndicator={false}
      keyExtractor={(s) => s.id}
      renderItem={({ item }) => <StoryTile story={item} onPress={onOpen} />}
    />
  );
}

CModal viewer — current segment

A fullscreen Modal shows the current segment image. The viewer is opened by a story id; resolve the story and clamp segmentIndex. Render-only here — navigation and the timer come in D/E.

function StoryViewer({
  stories, openId, onClose,
}: { stories: Story[]; openId: string | null; onClose: () => void }) {
  const storyIndex = stories.findIndex((s) => s.id === openId);
  const [segmentIndex, setSegmentIndex] = useState(0);

  const story = storyIndex >= 0 ? stories[storyIndex] : null;
  const segment = story?.segments[segmentIndex];

  return (
    <Modal visible={openId !== null} animationType="fade" onRequestClose={onClose}>
      <View style={styles.viewer}>
        {segment && (
          <Image source={{ uri: segment.uri }} style={styles.full} resizeMode="cover" />
        )}
        <Pressable style={styles.closeBtn} onPress={onClose}>
          <Text style={styles.closeTxt}>✕</Text>
        </Pressable>
      </View>
    </Modal>
  );
}

Reset segmentIndex to 0 whenever openId changes so a freshly opened story starts at its first frame — handled by an effect in the assembled hook below.

DAuto-advance — goNext / goPrev

Three transitions drive the machine. goNext rolls past the last segment into the next story, then closes after the last story. goPrev steps back, clamped at the first segment. Both reset the timer by virtue of changing segmentIndex (see the timer mechanism).

const goNext = () => {
  if (!story) return;
  if (segmentIndex + 1 < story.segments.length) {
    setSegmentIndex((i) => i + 1);                 // next frame, same story
  } else if (storyIndex + 1 < stories.length) {
    setStoryIndex((i) => i + 1);                   // roll into next story…
    setSegmentIndex(0);                            // …at its first frame
  } else {
    onClose();                                     // end of the last story → dismiss
  }
};

const goPrev = () => {
  if (segmentIndex > 0) {
    setSegmentIndex((i) => i - 1);                 // previous frame
  } else if (storyIndex > 0) {
    const prev = stories[storyIndex - 1];
    setStoryIndex((i) => i - 1);
    setSegmentIndex(prev.segments.length - 1);     // last frame of previous story
  }
  // else: already at the very first frame → no-op
};

EProgress bars + tap zones

One bar per segment, derived purely from segmentIndex: bars before the current are full, the current one fills over the segment duration, later bars are empty. Two full-height Pressable zones (left third = prev, right two-thirds = next) sit over the image. AppState pauses when backgrounded.

function ProgressBars({
  count, index, progress,
}: { count: number; index: number; progress: number }) {
  return (
    <View style={styles.bars}>
      {Array.from({ length: count }, (_, i) => {
        const fill = i < index ? 1 : i === index ? progress : 0;
        return (
          <View key={i} style={styles.barTrack}>
            <View style={[styles.barFill, { flex: fill }]} />
            <View style={{ flex: 1 - fill }} />
          </View>
        );
      })}
    </View>
  );
}

// tap zones, layered over the image inside the viewer:
<Pressable style={styles.zoneLeft} onPress={goPrev} />
<Pressable style={styles.zoneRight} onPress={goNext} />

Array.from({ length: count }, ...) gives a fresh bar array each render with no mutation; flex: fill vs flex: 1 - fill renders the partial fill without measuring pixel widths.

mechanismAuto-advance timer

The heart of the viewer. A useEffect keyed on (storyIndex, segmentIndex, paused) arms a single setTimeout(goNext, duration); its cleanup clearTimeout fires on every segment change or unmount. The stale-closure trap: if you forget the cleanup, old timers survive and fire goNext multiple times — segments skip. Keep goNext in a ref so the effect does not re-arm on every render.

const goNextRef = useRef(goNext);
goNextRef.current = goNext;                          // latest closure, every render

useEffect(() => {
  if (openId === null || paused || !segment) return; // no timer while closed / paused

  const duration = segment.duration ?? DEFAULT_DURATION;
  const id = setTimeout(() => goNextRef.current(), duration);

  return () => clearTimeout(id);                      // ◀ MUST clean up — kills the stale timer
}, [openId, storyIndex, segmentIndex, paused, segment]);

Pause / resume that respects elapsed time: store when the segment started and how much time was left; on pause, bank the remaining; on resume, re-arm for the banked remainder instead of the full duration — otherwise a pause restarts the frame.

const startedAtRef = useRef(0);
const remainingRef = useRef(DEFAULT_DURATION);

useEffect(() => {
  if (openId === null || !segment) return;
  const full = segment.duration ?? DEFAULT_DURATION;

  if (paused) {
    const elapsed = Date.now() - startedAtRef.current;
    remainingRef.current = Math.max(0, remainingRef.current - elapsed);  // bank what is left
    return;                                          // no new timer while paused
  }

  // (re)start: full duration on a fresh segment, banked remainder on resume
  const wait = remainingRef.current > 0 && remainingRef.current < full
    ? remainingRef.current
    : full;
  startedAtRef.current = Date.now();
  remainingRef.current = full;                        // reset budget for the next segment

  const id = setTimeout(() => goNextRef.current(), wait);
  return () => clearTimeout(id);
}, [openId, storyIndex, segmentIndex, paused, segment]);

assembleduseStories — the integration

One hook owns the whole machine: open/close, the two indices, paused, the elapsing progress for the bars, the timer with cleanup, and the navigation transitions. The screen below is a thin render of what it returns.

function useStories(stories: Story[]) {
  const [openId, setOpenId] = useState<string | null>(null);
  const [storyIndex, setStoryIndex] = useState(0);
  const [segmentIndex, setSegmentIndex] = useState(0);
  const [paused, setPaused] = useState(false);
  const [progress, setProgress] = useState(0);       // 0..1 fill of the current bar

  const story = openId !== null ? stories[storyIndex] : null;
  const segment = story?.segments[segmentIndex];

  const open = (id: string) => {
    const idx = stories.findIndex((s) => s.id === id);
    if (idx < 0) return;
    setStoryIndex(idx);
    setSegmentIndex(0);
    setProgress(0);
    setOpenId(id);
  };
  const close = () => { setOpenId(null); setPaused(false); };

  const goNext = () => {
    if (!story) return;
    if (segmentIndex + 1 < story.segments.length) { setSegmentIndex((i) => i + 1); }
    else if (storyIndex + 1 < stories.length) { setStoryIndex((i) => i + 1); setSegmentIndex(0); }
    else { close(); }
    setProgress(0);
  };
  const goPrev = () => {
    if (segmentIndex > 0) { setSegmentIndex((i) => i - 1); }
    else if (storyIndex > 0) {
      const prev = stories[storyIndex - 1];
      setStoryIndex((i) => i - 1); setSegmentIndex(prev.segments.length - 1);
    }
    setProgress(0);
  };

  const goNextRef = useRef(goNext);
  goNextRef.current = goNext;

  // drive both the auto-advance AND the progress fill from one rAF-ish interval
  useEffect(() => {
    if (openId === null || paused || !segment) return;
    const duration = segment.duration ?? DEFAULT_DURATION;
    const start = Date.now();
    setProgress(0);

    const tick = setInterval(() => {
      const p = Math.min(1, (Date.now() - start) / duration);
      setProgress(p);
      if (p >= 1) goNextRef.current();                // advance when the bar is full
    }, 50);

    return () => clearInterval(tick);                  // ◀ cleanup on segment / pause change
  }, [openId, storyIndex, segmentIndex, paused, segment]);

  // pause when the app is backgrounded
  useEffect(() => {
    const sub = AppState.addEventListener('change', (s) =>
      setPaused(s !== 'active'));
    return () => sub.remove();
  }, []);

  return {
    openId, story, storyIndex, segmentIndex, segment, progress,
    open, close, goNext, goPrev,
    pause: () => setPaused(true),
    resume: () => setPaused(false),
  };
}

function useStories(stories: Story[]) {
  const [openId, setOpenId] = useState<string | null>(null);
  const [storyIndex, setStoryIndex] = useState(0);
  const [segmentIndex, setSegmentIndex] = useState(0);
  const [paused, setPaused] = useState(false);
  const [progress, setProgress] = useState(0);

  const story = openId !== null ? stories[storyIndex] : null;
  const segment = story?.segments[segmentIndex];

  const open = (id: string) => {
    const idx = stories.findIndex((s) => s.id === id);
    if (idx < 0) return;
    setStoryIndex(idx); setSegmentIndex(0); setProgress(0); setOpenId(id);
  };
  const close = () => { setOpenId(null); setPaused(false); };

  const goNext = () => {
    if (!story) return;
    if (segmentIndex + 1 < story.segments.length) setSegmentIndex((i) => i + 1);
    else if (storyIndex + 1 < stories.length) { setStoryIndex((i) => i + 1); setSegmentIndex(0); }
    else close();
    setProgress(0);
  };
  const goPrev = () => {
    if (segmentIndex > 0) setSegmentIndex((i) => i - 1);
    else if (storyIndex > 0) { const p = stories[storyIndex - 1]; setStoryIndex((i) => i - 1); setSegmentIndex(p.segments.length - 1); }
    setProgress(0);

  const goNextRef = useRef(goNext);
  goNextRef.current = goNext;

    if (openId === null || paused || !segment) return;
    const duration = segment.duration ?? DEFAULT_DURATION;
    const start = Date.now();
    setProgress(0);
    const tick = setInterval(() => {
      const p = Math.min(1, (Date.now() - start) / duration);

      if (p >= 1) goNextRef.current();

    return () => clearInterval(tick);                  // ◀ cleanup kills the stale timer

  useEffect(() => {
    const sub = AppState.addEventListener('change', (s) => setPaused(s !== 'active'));

  return {
    openId, story, storyIndex, segmentIndex, segment, progress,
    open, close, goNext, goPrev,

}
