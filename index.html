Real-time Chat — Composite Build

Progressive block-by-block build: fetch history + optimistic send + live WebSocket + offline queue, converging on one React Query cache. Includes the useWebSocket & outbox mechanisms, the useChatSocket wrapper, dedup/reconcile, and the assembled screen.

Live Telemetry Tile — Composite Build

Dashboard of tiles updating live over WebSocket: a Zustand byId store as source of truth, a ~5Hz coalescing buffer, per-tile selector so only the changed tile re-renders, REST baseline + ts-guard.

Stories Viewer — Composite Build

Instagram-style stories: horizontal tiles, fullscreen viewer, a setTimeout auto-advance state machine, progress segments, tap zones, hold-to-pause, AppState handling.

Multi-step Form Wizard — Composite Build

Site-assessment wizard: one accumulated form + step index, per-step validation gating Next, progress, review, and an offline-safe submit via the outbox.

Infinite Feed + Search — Composite Build

Cursor-paginated useInfiniteQuery, pull-to-refresh, and a debounced race-safe search that swaps the queryKey (AbortSignal + placeholderData).
