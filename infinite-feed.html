Infinite Feed + Search — Composite Build

Progressive, block-by-block: cursor-paginated infinite list + pull-to-refresh + debounced race-safe search, all driven by one query.

Architecture & build order

One useInfiniteQuery is the list source. Three controls drive it: scroll fetches the next page, pull-to-refresh refetches, and the search term becomes part of the queryKey — so React Query caches per-term and aborts the in-flight request when the key changes.

useInfiniteQuery  ['items', debouncedSearch]   ← the list source
   ▲              ▲                ▲
   │              │                │
onEndReached      pull-to-refresh  search box
fetchNextPage     refetch          → debounced term in the queryKey
(cursor pages)    (RefreshControl) (new key → cache + abort old, signal)

data.pages.flatMap(p => p.items)   → flat array the FlatList renders

Build order — keep something runnable at every step: types → query → list → refresh → search → harden. Each step below leaves a working app.

Given helpers

const API_URL = 'https://example.com/api';

// Cursor pagination: pass the previous page nextCursor; null = first page.
// `signal` lets React Query abort this fetch when the queryKey changes.
async function getItems(
  cursor: string | null,
  q: string,
  signal?: AbortSignal,
): Promise<Page> {
  const url = `${API_URL}/items?limit=20&cursor=${cursor ?? ''}&q=${encodeURIComponent(q)}`;
  const r = await fetch(url, { signal });
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  return PageSchema.parse(await r.json());        // validate at the boundary
}

ATypes / data model

A Page carries its slice of items plus the nextCursor to fetch the following page — null means "no more." The cursor (not an offset) is what makes paging stable while new items arrive at the head.

import { z } from 'zod';

const ItemSchema = z.object({
  id: z.string(),
  title: z.string(),
});

const PageSchema = z.object({
  items: z.array(ItemSchema),
  nextCursor: z.string().nullable(),    // null → last page
});

type Item = z.infer<typeof ItemSchema>;
type Page = z.infer<typeof PageSchema>;

BuseInfiniteQuery — the spine

The whole feature hangs off this one hook. queryKey includes the debounced search so each term is cached and switching terms cancels the old fetch. getNextPageParam reads the cursor off the last page; flatMap flattens pages into one array for the list.

const {
  data, fetchNextPage, hasNextPage, isFetchingNextPage,
  isRefetching, refetch, status,
} = useInfiniteQuery<Page, Error>({
  queryKey: ['items', debouncedSearch],                 // ◀ term is part of the key
  queryFn: ({ pageParam, signal }) =>
    getItems(pageParam as string | null, debouncedSearch, signal),
  initialPageParam: null,                               // first page: no cursor
  getNextPageParam: (last) => last.nextCursor,           // null ends pagination
});

// pages → one flat array the list renders
const items = data?.pages.flatMap((p) => p.items) ?? [];

Because the term lives in the key, React Query keeps a separate cached page-stack per term and aborts the previous term’s in-flight fetch (via the threaded signal) the instant the key changes.

CList — onEndReached paging

Render the flat items. onEndReached asks for the next page, guarded so it fires once per page, not on every scroll tick. A footer spinner shows while the next page loads. Row is memoized; keyExtractor is stable.

const Row = memo(function Row({ item }: { item: Item }) {
  return (
    <View style={styles.row}>
      <Text style={styles.title}>{item.title}</Text>
    </View>
  );
});

<FlatList
  data={items}
  keyExtractor={(it) => it.id}                    // stable identity
  renderItem={({ item }) => <Row item={item} />}
  onEndReachedThreshold={0.5}                     // fetch at half a screen from the end
  onEndReached={() => {
    if (hasNextPage && !isFetchingNextPage) {       // guard: one page at a time
      void fetchNextPage();
    }
  }}
  ListFooterComponent={
    isFetchingNextPage ? <ActivityIndicator style={{ margin: 16 }} /> : null
  }
/>

The guard matters: without !isFetchingNextPage, a momentum scroll fires onEndReached repeatedly and stacks duplicate page requests.

DPull-to-refresh

A RefreshControl wired to refetch. refetch re-runs the query from the first page; isRefetching drives the spinner. This refetches the active term only — it does not reset the search.

<FlatList
  data={items}
  // ...keyExtractor / renderItem / onEndReached as above...
  refreshControl={
    <RefreshControl
      refreshing={isRefetching}                    // spinner while refetching
      onRefresh={() => void refetch()}              // re-run from page 1
    />
  }
/>

refetch refetches every loaded page for the current key by default, so the list does not collapse to a single page after a pull.

EDebounced search

A controlled TextInput holds the raw term; useDebounced derives the settled term that feeds the key. enabled skips empty/short queries; placeholderData keeps the previous results painted while the new term loads, so the list does not flash empty.

const [search, setSearch] = useState('');
const debouncedSearch = useDebounced(search, 300);     // settle 300ms after typing stops

const query = useInfiniteQuery<Page, Error>({
  queryKey: ['items', debouncedSearch],
  queryFn: ({ pageParam, signal }) =>
    getItems(pageParam as string | null, debouncedSearch, signal),
  initialPageParam: null,
  getNextPageParam: (last) => last.nextCursor,
  enabled: debouncedSearch.length === 0 || debouncedSearch.length >= 2,  // skip 1-char noise
  placeholderData: (prev) => prev,                     // keep old results while new term loads
});

// the input drives `search`; `debouncedSearch` drives the key
<TextInput value={search} onChangeText={setSearch} placeholder="Search…" />

Three things cooperate: debounce cuts requests to one per pause, the key caches per-term and cancels the prior fetch via signal, and placeholderData hides the loading flash. Together that is a race-safe search-as-you-type.

mechanismuseDebounced (generic)

A reusable hook: returns the input value only after it stops changing for delay ms. Each change clears the prior timer, so only the last value in a burst survives. Knows nothing about search — any rapidly-changing value can use it.

function useDebounced<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value);

  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);     // new keystroke cancels the pending update
  }, [value, delay]);

  return debounced;
}

Pairing this with the queryKey is what makes it race-safe: the key only changes once per settled value, and React Query aborts the previous term’s request when it does.

assembledFull useFeed

All five blocks in one hook: debounced term → keyed infinite query → flattened items + the paging/refresh controls the screen needs.

function useFeed() {
  const [search, setSearch] = useState('');
  const debouncedSearch = useDebounced(search, 300);

  const {
    data, fetchNextPage, hasNextPage, isFetchingNextPage,
    isRefetching, refetch, status,
  } = useInfiniteQuery<Page, Error>({
    queryKey: ['items', debouncedSearch],
    queryFn: ({ pageParam, signal }) =>
      getItems(pageParam as string | null, debouncedSearch, signal),
    initialPageParam: null,
    getNextPageParam: (last) => last.nextCursor,
    enabled: debouncedSearch.length === 0 || debouncedSearch.length >= 2,
    placeholderData: (prev) => prev,
  });

  const items = data?.pages.flatMap((p) => p.items) ?? [];

  const loadMore = () => {
    if (hasNextPage && !isFetchingNextPage) void fetchNextPage();
  };

  return {
    items, search, setSearch, status,
    loadMore, isFetchingNextPage,
    refetch, isRefetching,
  };
}

Mock layer — so the list shows up

Mock the backend so the list renders without a server, then swap for the real getItems in prod. A paginated mock source lets you see it scroll, page, and filter end-to-end before any backend exists.

// 200 rows to scroll through
const ALL: Item[] = Array.from({ length: 200 }, (_, i) => ({
  id: String(i),
  title: `Item ${i}`,
}));

const PAGE_SIZE = 20;

// Drop-in for getItems: filters by `q`, slices a page, returns the next cursor.
async function getItems(cursor: string | null, q: string): Promise<Page> {
  await new Promise((r) => setTimeout(r, 300));            // simulate latency

  const filtered = q
    ? ALL.filter((it) => it.title.toLowerCase().includes(q.toLowerCase()))
    : ALL;

  const start = cursor ? Number(cursor) : 0;               // cursor = index into filtered set
  const slice = filtered.slice(start, start + PAGE_SIZE);
  const next = start + PAGE_SIZE;

  return {
    items: slice,
    nextCursor: next < filtered.length ? String(next) : null,  // null → no more pages
  };
}

With this defined, the list paints the first 20 rows, loads 20 more each time you near the bottom, and re-pages from a filtered set the moment the debounced term changes. Swap mock getItems for the real fetch (one function) for prod.

Fast-start scaffold — minute 1 paste

One complete, runnable file: UI + styles ready, getItems mocked over a paginated source, useDebounced real, the infinite query wired. Paste it → the list scrolls + pages + filters immediately on mock data → then deepen the marked stubs.

import React, { useState, useEffect, memo } from 'react';
import {
  View, Text, TextInput, FlatList, ActivityIndicator,
  RefreshControl, SafeAreaView, StyleSheet,
} from 'react-native';
import {
  QueryClient, QueryClientProvider, useInfiniteQuery,
} from '@tanstack/react-query';

// ── types ──
type Item = { id: string; title: string };
type Page = { items: Item[]; nextCursor: string | null };

// ── mock backend (swap for real) ──
const PAGE_SIZE = 20;
const ALL: Item[] = Array.from({ length: 200 }, (_, i) => ({ id: String(i), title: `Item ${i}` }));

// (prod) add a `signal?: AbortSignal` param and thread it into fetch so key changes abort.
async function getItems(cursor: string | null, q: string): Promise<Page> {
  await new Promise((r) => setTimeout(r, 300));
  const filtered = q ? ALL.filter((it) => it.title.toLowerCase().includes(q.toLowerCase())) : ALL;
  const start = cursor ? Number(cursor) : 0;
  const slice = filtered.slice(start, start + PAGE_SIZE);
  const next = start + PAGE_SIZE;
  return { items: slice, nextCursor: next < filtered.length ? String(next) : null };
}

// ── mechanism: debounce ──
function useDebounced<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

// ── useFeed: the integration ──
function useFeed() {
  const [search, setSearch] = useState('');
  const debouncedSearch = useDebounced(search, 300);

  const {
    data, fetchNextPage, hasNextPage, isFetchingNextPage,
    isRefetching, refetch, status,
  } = useInfiniteQuery<Page, Error>({
    queryKey: ['items', debouncedSearch],
    queryFn: ({ pageParam }) => getItems(pageParam as string | null, debouncedSearch),
    initialPageParam: null,
    getNextPageParam: (last) => last.nextCursor,
    enabled: debouncedSearch.length === 0 || debouncedSearch.length >= 2,
    placeholderData: (prev) => prev,
  });

  const items = data?.pages.flatMap((p) => p.items) ?? [];
  const loadMore = () => { if (hasNextPage && !isFetchingNextPage) void fetchNextPage(); };

  return { items, search, setSearch, status, loadMore, isFetchingNextPage, refetch, isRefetching };
}

// ── UI: ready ──
const Row = memo(function Row({ item }: { item: Item }) {
  return (
    <View style={styles.row}>
      <Text style={styles.title}>{item.title}</Text>
    </View>
  );
});

function FeedScreen() {
  const {
    items, search, setSearch, status,
    loadMore, isFetchingNextPage, refetch, isRefetching,
  } = useFeed();

  return (
    <SafeAreaView style={{ flex: 1 }}>
      <TextInput
        value={search}
        onChangeText={setSearch}
        placeholder="Search…"
        style={styles.search}
        autoCorrect={false}
        autoCapitalize="none"
      />
      {status === 'pending' ? (
        <ActivityIndicator style={{ flex: 1 }} />
      ) : (
        <FlatList
          data={items}
          keyExtractor={(it) => it.id}
          renderItem={({ item }) => <Row item={item} />}
          onEndReachedThreshold={0.5}
          onEndReached={loadMore}
          refreshControl={
            <RefreshControl refreshing={isRefetching} onRefresh={() => void refetch()} />
          }
          ListFooterComponent={isFetchingNextPage ? <ActivityIndicator style={{ margin: 16 }} /> : null}
          ListEmptyComponent={<Text style={styles.empty}>No results</Text>}
        />
      )}
    </SafeAreaView>
  );
}

const queryClient = new QueryClient();
export default function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <FeedScreen />
    </QueryClientProvider>
  );
}

const styles = StyleSheet.create({
  search: { margin: 12, height: 40, borderWidth: 1, borderColor: '#ccc', borderRadius: 10, paddingHorizontal: 14 },
  row: { paddingHorizontal: 16, paddingVertical: 14, borderBottomWidth: 1, borderBottomColor: '#eee' },
  title: { fontSize: 15 },
  empty: { textAlign: 'center', color: '#888', marginTop: 32 },
});
